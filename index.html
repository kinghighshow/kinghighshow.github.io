PLIRS

The Pathology Laboratory Information Retrieval System turns years of Word reports into an archive the lab can search, view, compile and export, without ever changing the original files.

~290integration tests on real files
8fields pulled from every report
AES-256encrypted backup and restore

Viewer. The matching report opens in a sharp, lazily loaded PDF view with the search hit highlighted and the extracted fields beside it.

The problem

The lab keeps years of reports in Word files, with several patients in each file. Finding a past case or putting together a set of reports meant opening files one by one.

What I built

Drag-and-drop import with a live queue, extraction of name, age, gender, hospital, lab number, date, diagnosis and comment from each report table, ranked “Find similar cases”, and collections you can reorder and export as one PDF or as CSV and Excel. Word is used for conversion so letterheads stay intact, with LibreOffice as a fallback.

How it was tested

About 290 integration tests run against real Word files, a real SQLite database and real Qt signals instead of mocks. They caught a search crash on malformed input and two packaging failures before release. The code follows Clean Architecture, with domain, application and interface layers kept separate.

Built with

Python, PySide6 (Qt 6), SQLite with FTS5 and BM25 ranking, PyMuPDF, mammoth, BeautifulSoup, pywin32, PyInstaller and Inno Setup.

IntelliBin

A hospital waste sorter that sees each item, classifies it on a Raspberry Pi and drops it into the right bin.

97%accuracy in a 100-item real-time test
8–12 sfrom detection to deposit
6,868training images, 1,475 captured by our team
  1. DetectAn ultrasonic sensor notices an item.
  2. CaptureThe camera takes a frame.
  3. ClassifyMobileNetV2 picks one of five waste types on the Pi.
  4. SortStepper and servo motors route it to its bin.
One cycle per item, start to finish.Overall Best Project and Best Department Project, 2025

The problem

Hospital waste is often sorted by hand, and mixing categories creates infection and disposal risks for staff.

What I did

As first author, I assembled the dataset, fine-tuned MobileNetV2, deployed it on the Pi and wired the camera, sensor and motors into one cycle.

Read the paper

Built with

Python, TensorFlow and TensorFlow Lite, MobileNetV2, OpenCV, Raspberry Pi 4B and an OV5647 camera.

Have a problem computer vision could solve? Get a fixed quote

Prototype results from controlled testing. Pharmaceutical waste was the weakest class at 85%. Not clinically validated.
