# Sultan Atanda: Portfolio

Personal portfolio website: AI/ML projects, web design services, experience and contact.

Plain HTML and CSS with a few lines of JavaScript. No build step and no dependencies.

## Files

- `index.html`: the whole site
- `img/portrait-cut.webp`: hero portrait (background removed)
- `img/`: project screenshots (Lab Manager screens, shown with an empty database)

## Editing

Open `index.html`. Each section is marked with a comment (`<!-- SERVICES -->`, `<!-- PROJECTS -->` and so on). Colours and fonts are set once at the top of the `<style>` block.

## Publishing with GitHub Pages

Settings → Pages → Deploy from branch → `main` / root.
Note: Pages on a private repository needs a paid GitHub plan. On a free plan, make the repo public or rename it `kinghighshow.github.io`.
